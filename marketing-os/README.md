# Elite Way Marketing OS

Separate from the public site and from Closer OS.

**Suggested subdomain:** `marketing.eliteway.co.za`

Open desk. No password. Instagram, LinkedIn, X. Prepare captions, carousels, video notes, email copy. Team still publishes in the native apps. Design leaves room for APIs later.

## Upload

```bash
cd marketing-os
npm install
npm run build
```

Upload contents of `dist/` to the subdomain document root.
